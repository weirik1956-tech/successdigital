PORTFOLIO IMAGES
Put your three project image files in this same main folder:
- your-image1.png  (The Celebration Edit)
- your-image2.png  (Studio North)
- your-image3.jpg  (The Good Notes)

The project cards are clickable. Clicking one opens a larger preview dialog.
If an image filename does not match or the image is missing, the preview will
show a helpful message. You can change the filenames in index.html and
js/main.js if your images use different names.

The Good Notes is positioned as a digital planner concept: daily and weekly
planning pages, notes, and goal-setting templates.
